# API scopes

Generated by `npm run docs:scopes` from the running router and `src/platform/auth/scopes.js`.
`tests/scopes.test.js` fails the build when this file no longer matches the code.

| Scope | Grants |
|---|---|
| `read` | every GET, and the computations that store nothing |
| `write` | create, change or delete a record |
| `lock` | lock an assessment — it enters the disclosure |
| `assess` | run an engine that persists a run or calls an AI agent |
| `admin` | reserved; no route requires it yet |

A key issued before scopes existed carries none: it keeps everything it could do, every response on it says
`X-Key-Scopes: unscoped`, and `npm run key:list` counts them. `npm run key:scope -- <key-id> --scopes …` applies scopes.
A signed-in user's scopes follow the role level: administrator everything; credit officer and ESG analyst read, write, lock, assess;
relationship manager read, write, assess; auditor and borrower read.
